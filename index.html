2026 暑期地球物理探勘與 CLIL 雙語教學

融合地球科學專業知識、AI 代理工具自動化應用，以及國小雙語防災探究教案設計。

一、 課程概述

本課程為期五週（7/17 - 8/14），核心主軸從環境建置與工具啟動，經折射震測與資料分析，最終發展至 CLIL（內容和語言整合學習）防災探究與英文成果發表。課程內容結合地球科學專業知識、資訊科技工具以及雙語教學設計，旨在全面實務應用地球物理探勘技術與教學發展。

二、 五週課程進度與重點摘要

週次/日期 課程主題 實作任務
W01 (7/17) 課程緣起、環境建置、工具介紹 完成個人地震學課程工具包
W02 (7/24) 折射震測原理：探測校園底下的構造 完成簡易震測實作
W03 (7/31) AI 工具使用：Antigravity IDE 完成震源定位教案簡報
W04 (8/7) 折射震測原理 CLIL 教學、Antigravity 報告與網頁、報告練習 Antigravity 報告網頁建立
W05 (8/14) CLIL 防災探究（2）：地震波頻率與地層探測分析 地震探測分析報告

三、 核心技術與理論學習重點

1. 網頁建置與雲端部署

結合大語言模型（如 Gemini）輔助生成網頁程式碼 (index.html)，並將其部署至 GitHub Pages。透過 GitHub 免費雲端空間建立對外服務的靜態網頁，作為技術文件、程式碼及教案的展示平台。

2. AI 代理與自動化工具應用

  • Google Antigravity IDE： 自動化 AI 代理，可操作本機檔案、自動寫入與編修，並提供視覺化界面檢視。
  • Google Apps Script (GAS)： 串接 Google 表單與試算表，自動收集學生報告資料並即時寄發確認信件。

3. 地球物理震測實驗與原理

  • 折射震測實務： 無破壞性探測，透過人工震源與地震儀陣列解構地下構造。
  • 震波傳播特性： 解析「直達波」與「折射波」，探究遠距離折射波早到的高速地層傳播現象。
  • 建築共振反應： 使用黏土與竹籤物理模擬，實證不同高度建築遭遇不同頻率震波時的動態反應差異。

4. CLIL 雙語教案與 Prompt 工程

結合 IRIS 開源資源與 Prompt 工程，為國小 5-6 年級打造專屬教案：

引起動機 Warm-up 震央/震源影音解析 雙語核心能量站 互動挑戰與反思
