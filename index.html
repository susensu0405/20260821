一、 課程概述

本課程為期五週（7/17 - 8/14），核心主軸從環境建置與工具啟動，經折射震測與資料分析，最終發展至 CLIL（內容和語言整合學習）防災探究與英文成果發表。課程內容結合地球科學專業知識、資訊科技工具以及雙語教學設計，旨在全面實務應用地球物理探勘技術與教學發展。

三、 核心技術與理論學習重點

1. 網頁建置與雲端部署

結合大語言模型（如 Gemini）輔助生成網頁程式碼 (index.html)，並將其部署至 GitHub Pages。透過 GitHub 免費雲端空間建立對外服務的靜態網頁，作為技術文件、程式碼及教案的展示平台。

2. AI 代理與自動化工具應用

  • Google Antigravity IDE： 作為可直接操作電腦本機與環境檔案的 AI 代理。能自動生成內容並寫入資料夾，支援檔案編修，並提供視覺化介面供人工檢視。
  • Google Apps Script (GAS)： 應用於串接 Google 表單與試算表。設定自動化腳本：當學生填寫表單繳交期末報告與 Email 後，系統會自動收集資料至試算表，並同步寄發確認信件。

3. 地球物理震測實驗與原理

  • 折射震測實務： 在不破壞地表的前提下，透過產生人工震源與佈設地震儀陣列來探測地下構造。
  • 震波傳播特性分析： 地震儀主要接收「直達波」與「折射波」。
    思考：為什麼遠距離測點會先收到折射波？
    直達波雖然路徑最短，但僅在低速的地表淺層傳遞；折射波雖然路徑較長（需向下傳播至臨界角並沿介面傳遞），但因為進入深層高聲速/高速地質構造中，傳播速度顯著提升。當距離足夠遠（超過臨界距離）時，折射波累積的速度優勢會補償多走的路徑，因而比直達波更早到達接收器。
  • 建築共振反應： 探討地震波包含不同頻率成分對各種地層與建築物的影響。透過黏土與竹籤的物理模擬實驗，實證不同高度的建築物在遭遇不同頻率震波時的動態反應差異。

4. CLIL 雙語教案開發與提示詞工程

善用國外開源資源（如 IRIS 平台），結合提示詞工程引導 AI 產出適合國小高年級（5~6年級）的雙語教案。設計模組包含：

  • 引起動機（Warm-up）： 透過生活化比喻帶入地震概念。
  • 影音解析： 解構震央 (Epicenter) 與震源 (Focus/Hypocenter) 的空間概念。
  • 雙語能量站： 萃取核心單字與句型，附帶中文翻譯及跟讀引導。
  • 互動挑戰與課程反思： 將複雜科學知識生活化。
